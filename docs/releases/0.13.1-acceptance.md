# 0.13.1 acceptance — candidate

Baseline: main `cadb33d3c039191f86fc2ce3a30fe961669cd775` (v0.13.0).
This patch addresses Issues #35/#36 without changing UI, SSH configuration or DSH.

## Reproduction and implemented boundary

- #35: official worker construction used Host Node/bootstrap/sandbox paths but
  the generic SSH subprocess route forwarded those paths literally and did not
  carry fd 7. The adapter now uses the *active* official SDK worker, remote Node
  discovery and policy, and a separately bounded/acknowledged duplex channel.
- #36: a raw local Unix client received protocol hello and could create a new
  session without proving possession of control credentials. The regression was
  red before the fix. Authentication, peer UID checking, directional records,
  replay rejection and namespace hiding are now tested. Same-UID unrestricted
  malware is not claimed to be isolated; read-only socket permissions alone are
  not claimed to be confinement.
