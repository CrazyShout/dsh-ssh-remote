# 0.13.5 — Translated diagnostics and clearer sandbox requirements

## Changes / 更新

- PR #44–#46, contributed by @rusliksu: translate Host-provided connection/workbench messages and register a Russian dictionary through the official DSH locale service. Unknown diagnostics and captured path/error values are preserved. Russian copy is machine-assisted; native-speaker corrections are welcome.
- Limit formatted-text translation to four explicit Host templates. This avoids matching arbitrary UI templates against long diagnostic output.
- Issue #47: report remote platform, missing executable, failed probe exit and timeout separately. State the required bubblewrap `--bind-fd` capability and the actual remote helper location. Upstream 0.9.0 lacks this option; some older distribution builds include backports. No permission relaxation or path-based fallback is introduced.
- 中文：补齐连接与工作台提示翻译、增加俄语词典；修复翻译匹配长错误文本时的卡顿。沙箱错误明确区分远端系统、程序缺失、探测退出和超时，并说明 `--bind-fd` 要求。没有绕过沙箱；报告者的机器仍需验证该能力。

## Installation / 安装

Use the official Desktop/Web plugin page:

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.5/dsh-ssh-remote-0.13.5.tgz
```

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.5/dsh-ssh-remote-0.13.5.tgz'
```

Runtime dependencies still download during installation. Save work before reloading; Desktop and Web profiles are separate. Check the archive against `SHA256SUMS`.

## Compatibility / 兼容范围

- DSH compatibility targets: `0.2.0-rc.2`, `0.2.1-rc.2`, `0.2.1-rc.3`, `0.2.2-rc.1`.
- Helper: `0.13.5`; content SHA-256: `95749359a6a0b6523fd34ac951eb78baf97757da4f5b8b0ab3aea7095ab14708`.
- No new runtime dependency or Host RPC. Sandbox commands, SSH routing, workspace IDs and transfer format v1 are unchanged.
- Release acceptance results are added after verification. A candidate or merged change is not proof of installation on the reporter's host.

## Rollback / 回退

Keep [v0.13.4](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.4) available. Install its fixed `.tgz` through the same official plugin page and reload after saving work. Rolling back does not add `--bind-fd` to an unsupported remote bubblewrap.
