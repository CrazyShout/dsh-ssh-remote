# 0.13.1 — Remote run_code and authenticated helper transport

## 中文

- 修复 [#35](https://github.com/CrazyShout/dsh-ssh-remote/issues/35)：官方 `run_code` worker、工作目录、独立控制通道和权限策略全部进入 SSH 执行环境；兼容 DSH 0.2.1 的持久内存模式。
- 修复 [#36](https://github.com/CrazyShout/dsh-ssh-remote/issues/36)：helper Unix 连接先认证再初始化，并校验消息完整性与序号。控制目录对文件 RPC 和受限进程不可见。
- 远端 PTC 需要支持 `stripTypeScriptTypes` 的 Node（22.13+ 或较新版本），受限权限需要 bubblewrap；不安装软件、不修改 SSH/PATH、不回退本机或完全权限。
- helper 升为 0.13.1。保存草稿和任务后重载插件并重连，旧 daemon 不会被原地修补或强制结束。未限制的同 UID 程序仍在安全边界之外；Unix hop 的完整性校验不替代外层 SSH 加密。
- Zod 4.6.6 修复已公告的资源消耗问题。DSH 本身不升级。

## English

Remote PTC reuses the active official Node worker with an authenticated helper,
matching remote cwd and sandbox, and a separate bounded/lossless fd-7 channel.
Persistent state remains owned by the official runtime and cannot silently move
between workspaces. Missing Node or confinement support fails explicitly.
No local execution, privilege escalation, software installation or SSH edits are
used as fallback. Reload and reconnect to activate helper 0.13.1; old daemons are
not patched in place. Unrestricted same-UID programs remain outside the boundary.

Tested DSH targets: **0.2.0-rc.2, 0.2.1-rc.2**. See the
[acceptance record](0.13.1-acceptance.md) for exact evidence and pending gates.

## Install / 安装

Paste into DSH's Plugins page, or use the Web profile CLI:

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.1/dsh-ssh-remote-0.13.1.tgz'
```

The archive includes built Host/Client assets and helper files; runtime
dependencies are still fetched by the official installer. Verify the attached
`SHA256SUMS`. Older tags/assets remain immutable, but pre-0.13.1 rollback loses
the authentication fix and is only recommended for isolated diagnostics.
