# v0.11.0 — Unified remote workbench / 统一远程工作台

## 中文

- **破坏性变更**：移除 SSH2/SFTP 后端及其两个终端导出。统一使用 system OpenSSH + Python helper；旧主机通过显式预览、确认、备份、验证和回滚向导迁移。
- 快速打开、文件传输、端口转发和终端状态合并为远程工作台；保留官方文件树、预览、终端，以及编辑草稿保护。支持键盘选择、窄面板菜单和按需状态刷新。
- 同批双文件并发、按页清单读取、节流进度、预计算 Top-K 搜索；范围读取直接从指定偏移开始，单次最多 192 KiB，跨块核对文件版本。
- 修复 DSH_HOME 路径别名下的 anchor 恢复；损坏映射明确报错。

目标兼容基线：DSH **0.2.0-rc.2 / 0.2.1-rc.2**；helper **0.11.0**。显式接受新版 RC 的 peer 版本范围；两版原生终端协议分别回归，插件不接管输入和控制权。传输清单仍为 v1。安装仍需下载运行依赖，但不再引入本插件的 ssh2/cpu-features 原生构建。

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.11.0/dsh-ssh-remote-0.11.0.tgz
```

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.11.0/dsh-ssh-remote-0.11.0.tgz'
```

先保存草稿、暂停传输，再重启对应服务。迁移不自动执行；详见仓库的迁移指南。回退使用 v0.10.2 的正式安装包，已迁移的 OpenSSH 配置不会自动删除。

## English

Breaking: SSH2/SFTP and the two legacy terminal exports are removed. Existing OpenSSH aliases work as before; old plugin hosts require the explicit migration wizard (preview, confirm, private backup, verify, guarded rollback).

The remote workbench combines quick open, transfers, ports and terminal status while preserving native files/terminals and editor draft protection. Keyboard selection, responsive navigation, demand-driven polling, real cross-file concurrency, page-level manifest reads, throttled progress, prepared Top-K search and capability-negotiated direct range reads improve daily use.

Baselines: DSH 0.2.0-rc.2 and 0.2.1-rc.2; helper 0.11.0; durable transfer format v1. Peer ranges explicitly accept the new RC, with both native terminal transports covered by regression tests. Install the complete archive URL above, verify `SHA256SUMS`, enable and restart. Do not use the unrelated same-name npm package. v0.10.2 remains available for rollback on its validated DSH 0.2.0-rc.2 baseline.

## Limits / 边界

Editor limit remains 256 KiB; transfers remain 1 TiB per file/batch, with small-data functional checks and simulated capacity boundaries, not TB-scale throughput measurements. No Windows-remote support, native external-editor takeover, or model-terminal resize is added. Performance figures in the acceptance record are synthetic local benchmarks, not network throughput claims.
