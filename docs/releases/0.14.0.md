# 0.14.0 — Switch branches in an SSH workspace

Thanks to @weijie-5 for [PR #53](https://github.com/CrazyShout/dsh-ssh-remote/pull/53).

**使用**：启用 DSH Forge，在 SSH 工作区打开尚未开始首轮的会话，点 **切换分支**。搜索只列分支名，不写入 Git 引用；选中远端分支后才拉取它并建立本地跟踪分支，也可以基于当前 HEAD 新建分支。已有同名本地分支时须明确选本地分支，不会替你覆盖或切换。

**Behavior**: Search without changing refs; fetch the selected remote head only when switching. After switching, the control attempts a fast-forward-only pull when an upstream exists. If the update fails, the switch is not undone. No force checkout, automatic stash or rebase. Changes run in the SSH session's working directory with its sandbox policy and Agent maintenance; read-only sessions cannot change branches. Local sessions and the official worktree control are unchanged.

**Install / 安装**: Paste this URL into the official Desktop or Web plugin installer:

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.14.0/dsh-ssh-remote-0.14.0.tgz
```

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.14.0/dsh-ssh-remote-0.14.0.tgz'
```

Desktop and Web use separate profiles. Save work before reloading. Requires remote Git; the new control also needs Forge and the host's working-directory service. The helper remains 0.13.5; no new helper deployment is needed for this release. Roll back with the [v0.13.8 installation package](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.8).
