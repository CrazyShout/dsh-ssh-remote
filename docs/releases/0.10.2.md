# 0.10.2 — Easier installation / 更容易安装

## 中文

- 提供可直接在 DSH 官方插件页面安装的预构建包，不用克隆仓库或编译。
- 重写中英文 README，将安装、首次 SSH 连接和日常入口放在前面；历史更新和详细排错独立成页。
- 增加安装包完整性检查，以及全新安装、启停、升级、回退和卸载验收。
- SSH 路由、文件传输和终端协议不变。helper 仍为 0.10.0，内容哈希不变。

已验收基线：DSH **0.2.0-rc.2**、macOS/Linux 本机、Node 22/24；真实 SSH 功能使用 Linux 远端的小样本验收。Desktop 使用自带运行时。

在 **插件 → 添加插件** 粘贴：

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.10.2/dsh-ssh-remote-0.10.2.tgz
```

Web CLI：

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.10.2/dsh-ssh-remote-0.10.2.tgz'
```

安装后点击 **立即启用**，然后重启对应 DSH。运行依赖仍需联网下载，依赖构建提示使用官方确认与重试。npm 同名包属于其他项目，请使用上面的完整地址。

## English

Prebuilt packages can now be installed directly through the official DSH plugin page. The bilingual README starts with installation and first connection, with separate history and troubleshooting documents. Release checks exercise actual package installation, enabling/disabling, upgrades, rollback and removal.

Validated baseline: DSH **0.2.0-rc.2**, macOS/Linux hosts, Node 22/24, and small live-SSH samples on Linux. Helper **0.10.0** and its content hash are unchanged. Paste the package URL above into the plugin installer, or use the Web CLI command. Restart the corresponding DSH instance afterwards.

Runtime dependencies still require network access and may prompt for build approval. The unscoped npm name belongs to another project.

## Known limits / 已知限制

- Windows hosts are not validated; forwarding requires a macOS/Linux host.
- Text editing is limited to complete UTF-8 files up to 256 KiB. Transfers support 1 TiB boundaries by simulation, not TB-scale performance testing.
- Native local-open/Finder actions are not SSH editor actions. Existing DSH v0 history conversion errors are outside this plugin release.
- Rollback: install `github:CrazyShout/dsh-ssh-remote#abff63bafd0959820ec2d9976803f5cdbdc77580` (0.10.1) and restart.
