# v0.13.2 — Updates and workspace polish

## 中文

- 更新检查失败不再沿用六小时成功缓存的检查间隔：页面可见且自动检查开启时，五分钟后复查；隐藏页面不轮询。
- 错误就近显示，网络、超时、限流及发布校验错误分别说明；详情仅保留阶段与脱敏错误码，不输出代理凭据或响应正文。
- 工作台窄面板分区菜单更易发现；快速打开突出文件名、弱化父目录，把帮助和显式编辑放在底部。官方文件、终端、草稿保护及一键更新流程不变。
- 兼容验收包含 DSH 0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.3。helper 保持 0.13.1 与原哈希。

固定安装地址：

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.2/dsh-ssh-remote-0.13.2.tgz
```

安装包无需编译，但官方安装器仍需联网获取运行依赖。源码链接不会被包更新覆盖。远端 `run_code` 需要登录环境可发现支持 TypeScript stripping 的 Node；插件不会自行安装 Node 或修改 shell 配置。请按 DSH 返回结果保存工作并重新加载；不会自动结束终端。

## English

Visible automatic update checks recover after five minutes on failure, then return to six-hour success checks. Sanitized diagnostics distinguish network, timeout, HTTP and release-verification failures; transport credentials and response bodies are never displayed. Narrow navigation, file-name/directory hierarchy and update cards are refined while preserving native file/terminal/installer workflows.

Tested DSH versions: 0.2.0-rc.2, 0.2.1-rc.2 and 0.2.1-rc.3. Helper 0.13.1 is unchanged. The archive contains compiled code; runtime dependencies still require network access. Source links are never replaced. Remote PTC still needs an appropriate Node on the remote login PATH; no automatic runtime or shell configuration changes are made.

Rollback: [v0.13.1](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.1). See [acceptance](0.13.2-acceptance.md) and `SHA256SUMS` for this release's verification boundary.
