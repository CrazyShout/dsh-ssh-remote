# 0.13.6 — Windows Git routing over SSH

## Changes / 更新

- Fix #49 through PR #50: Windows-resolved Git and the published Windows ACL runner no longer reach a Linux SSH host as unusable Windows paths. Thanks to @weijie-5 for the implementation and reported Windows-to-Linux verification.
- Preserve POSIX absolute/relative executable paths, including `.exe` names. Translate only recognized Windows paths and the built ACL runner contract; unknown/duplicate wrapper options and mismatched SSH workspaces fail closed.
- Retain remote read-only/workspace-write enforcement, hide helper control directories after writable mounts, and use FD binds for `/tmp` workspaces. Caller environment is applied inside the sandbox. Python starts in isolated mode before importing any launcher module.
- The official subprocess provider still owns stream collection and lifecycle. No Host RPC or runtime dependency was added. Helper remains 0.13.5 with unchanged content hash.
- 中文：修复 Windows Git 面板把本机路径发到远端的问题；保留远端 POSIX 文件名、受限权限和控制目录隔离。额外修复启动 Python 时可能加载工作区模块的问题。不升级 DSH、不自动改 SSH 配置。

## Install / 安装

Paste into the official Desktop/Web plugin page:

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.6/dsh-ssh-remote-0.13.6.tgz
```

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.6/dsh-ssh-remote-0.13.6.tgz'
```

Runtime dependencies still download during installation. Save work before a required reload; Desktop and Web profiles are separate. Verify the archive against `SHA256SUMS`.

## Compatibility and acceptance / 兼容与验收

- DSH targets: 0.2.0-rc.2, 0.2.1-rc.2, 0.2.1-rc.3, 0.2.2-rc.1, 0.2.2-rc.2, 0.2.2-rc.3.
- Helper 0.13.5 SHA-256: `95749359a6a0b6523fd34ac951eb78baf97757da4f5b8b0ab3aea7095ab14708`.
- Existing workspace identities, native terminal/file entry points and transfer format v1 are unchanged. Remote Git and a working bubblewrap are still required for restricted commands.
- This does not translate arbitrary custom runners or fix every platform's local executable paths. Source-only Node/TypeScript sandbox runners are rejected. The separate environment investigation in #47 remains open.
- Final CI and actual-package acceptance results will be appended to the Release after verification. Maintainer SSH smoke uses Windows-shaped argv from macOS; it is not a claim of personally testing a Windows Desktop GUI.

## Rollback / 回退

Keep [v0.13.5](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.5) available. Install its pinned archive using the same official plugin page, then reload after saving work. That version does not contain the Windows Git routing fix.
