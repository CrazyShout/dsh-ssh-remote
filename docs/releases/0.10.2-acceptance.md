## 观察与边界

- Desktop 首次连接曾返回一次 `remote helper stdout ended`；手动重试成功，后续预览与终端通过。没有据此声称修复连接层异常，本版不更改该层。
- Desktop 使用固定本地监听端口，测试实例不能和原 Desktop 同时启动；经用户授权正常退出原实例，再进行隔离验收。没有修改桌面安装包。
- 全程未发送模型请求。真实 SSH 只访问自己创建的小文件测试目录，未做大数据传输或 TB 性能测试。
- Windows 未验收。资产需要从 GitHub 下载，运行依赖仍需联网；这不是离线全依赖包。
