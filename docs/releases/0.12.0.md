# 0.12.0 — Easy installation and in-app updates

## 中文

- README 首屏提供横幅、用途与三步安装，换成无接管标志、无虚拟鼠标的实际 Web 截图。
- **插件 → dsh-ssh-remote → 检查更新**：自动检查稳定版，发现更新时轻量提醒；由用户确认后调用 DSH 官方安装服务。
- 自动检查可关闭。源码链接安装使用 Git 同步，不被安装包替换；不自动批准依赖脚本、不自动重启 DSH。
- 更新可能重载插件并结束 SSH 终端、转发或中断传输，请先保存草稿、暂停传输。结果未知时重新确认，不盲目重装。

## English

- Installation-first README with a new banner and clean screenshots from the actual Web UI.
- Stable-release checks and a one-time notice inside DSH. Confirm an update in the existing plugin details page; installation runs through the official package manager.
- Automatic checks can be disabled. Development links remain Git-managed. No automatic build-script approval, self-removal or app restart.
- Save drafts and pause transfers before updating: plugin reload may end SSH terminals/forwarding. Lost responses are reconciled, not silently retried.

## Install / 安装

Paste into **Plugins → Add plugin / 插件 → 添加插件**:

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.12.0/dsh-ssh-remote-0.12.0.tgz
```

For CLI / Web:

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.12.0/dsh-ssh-remote-0.12.0.tgz'
```

The npm package with the same name belongs to another project. Use this full URL. Runtime dependencies are still downloaded during installation. Version 0.11.2 and earlier need one manual installation to gain the new updater. Save work and fully restart the current DSH after that first upgrade so the new Host service is available.

## Compatibility and limits

Targets: DSH 0.2.0-rc.2 / Desktop 0.2.1-rc.2. helper 0.11.0 and its SHA-256 remain unchanged. Transfer format v1 and existing capacity limits are unchanged. No TB-scale performance claim.

Package files being installed does not prove running-code activation. DSH may require a restart or reject direct replacement of a source; the feature reports this instead of removing the current plugin. GitHub network failures/rate limits are not reported as up to date. Read-only checks never send project content or SSH configuration. Automatic checks run only while visible, at six-hour intervals, with a shared Host cache.

Rollback: retain [v0.11.2](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.11.2). Install that pinned archive manually; source-linked development checkouts remain separately Git-managed. This release does not update DSH or SSH configuration.
