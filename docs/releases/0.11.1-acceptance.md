- Web 和 macOS Desktop 均使用 DSH 0.2.1-rc.2 和独立 profile；Desktop 使用官方插件页面安装实际 `.tgz`、启用并正常重启。未修改默认 profile、DSH 版本或 SSH 配置。

- 两端均从原生 `/` 菜单选择远端项目技能，插入官方引用，再点击引用打开原生 SKILL.md 预览，读取到 `PROJECT_SKILL_REMOTE_0111`。测试草稿清空，没有发送模型请求。
