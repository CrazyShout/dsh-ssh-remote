# 0.13.0 acceptance

Validated 2026-10-20 from `4a0b113` (including PR #33), with final code candidate `07ac0d6`. This record describes candidate acceptance; the immutable GitHub Release and its public asset checksums are the publication evidence.

## Implemented scope

- Shared settings/header/workbench observer; no overlapping requests after timeout.
- Configuration discovery separated from remote probes; local/SSH sources load independently.
- Official DSH locale binding, balanced Chinese/English copy, native controls and contextual guidance.
- Transfer progress belongs to its task. Folder capability hints precede permission requests.
- No helper/hash change, SSH configuration edit, DSH upgrade or model request.
- Native workbench tabs remain mounted so opening a file preview does not discard the query; hidden tabs stop identity/status reads.
- Context framing follows the DSH language. The existing terminal-context response adds optional sanitized `output`; old clients retain `text`, and new clients preserve old Host responses verbatim. No new RPC or helper change.
