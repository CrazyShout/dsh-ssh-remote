# 0.11.0 验收记录 / Acceptance

状态：候选版本验收中，尚未合并或正式发布。以下不代表公开安装包已发布。

## 运行时与兼容

- CLI 基线保留 DSH `0.2.0-rc.2`；新增独立 `0.2.1-rc.2` Web 安装与 SDK 检查。
- 用户自行升级的 macOS Desktop 为 `0.2.1-rc.2`，内置 Node `24.21.0` / pnpm `11.28.5`。桌面功能在独立 DSH_HOME 和 Electron 数据目录验收，没有修改默认配置。
- 旧 peer 范围不接受下一补丁版本的预发布包；现显式加入 `0.2.1-rc.2`，而非宣称所有 alpha 都兼容。
- 新终端协议使用公开双向 attach 流；插件仍只路由官方 subprocess 并在公开 create 请求中关联状态。测试分别覆盖新旧协议的输入、resize、控制权、恢复屏幕与释放。
- 候选包已在新版 CLI 独立 profile 完成安装、启用启动、停用、卸载和工作区原文件保留；无需编译本插件。

## 已完成的真实闭环

- 新版 Desktop：添加 hk-wsl 临时工作区；键盘快速打开、官方预览、原生 `@` 引用跳转均读到远端标记。
- 新版 Desktop：官方新建终端的 `pwd` 指向远端临时目录；`false` 的退出码 1 在工作台状态页正确显示。测试终端已通过 `exit` 结束，没有发送模型请求。
- 新版 Desktop：8 MiB 二进制文件、中文/空格名称、45 字节文本及空目录上传下载成功；切换工作台分区期间上传继续；模拟 `.env` 被默认排除。
- 二进制往返 SHA-256：`218ea497c3ab90c6d3058d5fd1a1313bd5c2bb4a1762c7cc88d8e0087157f168`；文本往返 SHA-256：`e74cdb319a4b8e836c885992bd08e5bd5013e57c45a3834be1c659ffdeb065a4`。实际传输约 16 MiB，不是 TB 吞吐测试。
- hk-wsl：0.10.2 创建的 28 字节传输在 0.11.0 保留确认偏移 8 并显式继续；格式仍为 v1。

## 性能与安全边界

- Python helper 和 Host 都验证跨文件并发、单文件有序；旧 helper 的独占锁仍排斥新版共享数据锁。
- 200 项清单每页只读一次；可变回执仍读取当前状态。50,000 候选 Top-K 与旧排序结果一致。
- 合成排序基准 P95 分别从 14.97→1.55、25.61→11.14、19.34→10.78 ms；这是本机算法基准，不是 SSH 吞吐数据。
- 迁移测试使用临时 SSH 配置；未自动迁移用户真实配置。helper 0.11.0 哈希为 `3c3b35a6a6c20703053cb06d8ee770031d92266750d7909bc41e96087f8d09be`。
- 1 TiB 边界仍使用模拟偏移和流验证；Windows 本机、TB 级性能未实测。
