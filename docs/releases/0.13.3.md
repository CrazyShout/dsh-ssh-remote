# v0.13.3 — Update recovery

## 中文

- 检查更新会重新核对当前安装和运行版本。文件已更新但激活失败时，两种状态分别显示。
- 安装结果未知时仍可检查。旧请求已不在当前 Host 中、当前版本也已核对后，可确认“结束这次提示”；这不表示安装已取消，不会自动重装。
- 更新记录不再存完整日志；旧格式会转换成摘要。详情保留短诊断和可复制日志路径。

固定安装地址：

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.3/dsh-ssh-remote-0.13.3.tgz
```

安装使用 DSH 官方服务。更新可能重载插件；请保存草稿、暂停传输，并按结果提示重启。安装包无需自行编译，运行依赖仍需联网下载。

## English

Update checks refresh installed and running versions independently of GitHub availability. Unknown results no longer block read-only checks. Once the old request is no longer active in this Host and installation facts have been refreshed, the user may dismiss its notice; this neither cancels an installation nor reinstalls automatically. Bounded summaries replace full persisted installer logs, with legacy migration and explicit unreadable-record diagnostics.

Supported verification matrix remains DSH 0.2.0-rc.2 / 0.2.1-rc.2 / 0.2.1-rc.3. Helper 0.13.1 and its hash are unchanged. No new runtime dependency or Host RPC.

Rollback: [v0.13.2](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.2). See [acceptance](0.13.3-acceptance.md) and the published SHA256SUMS.
