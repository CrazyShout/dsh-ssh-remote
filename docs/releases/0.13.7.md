# 0.13.7 — Remote Git recovery without stale blocking

## Changes / 更新

- PR #51 reduces repeated failed Git status probes. Thanks to @weijie-5 for the initial implementation; maintainer review narrowed the scope and added recovery/lifecycle regressions.
- Identical workspace, argv and environment share a small negative cache; other projects and queries remain independent. Keys are SHA-256 fingerprints held only in memory (64 entries maximum), not retained command contents or credentials.
- An actual helper reconnect clears the cache immediately. Without that notification, a monotonic 2-second cooldown admits one recovery query; a successful query reopens normal traffic. This feature does not create automatic retries or new connections.
- Old outcomes cannot override newer results or a reconnected/reloaded instance. Cancelled handles, expected Git exits, local commands, writes and piped-input queries are not counted as infrastructure failures.
- Read-only classification excludes symbolic-ref writes, output-file flags, ambiguous wrappers and custom config. Existing DSH ownership of subprocess streams, cancellation and teardown is unchanged.
- 中文：减少重复 Git 报错，同时避免恢复后仍被拦住、一个项目影响另一个项目，或取消操作被算成连接故障。不是新的主机离线判定，也不会自动重连或重试。

## Install / 安装

Paste into the official Desktop/Web plugin page:

```text
https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.7/dsh-ssh-remote-0.13.7.tgz
```

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.7/dsh-ssh-remote-0.13.7.tgz'
```

Save work before reloading. Runtime dependencies still download at installation; Desktop and Web use separate profiles.

## Compatibility / 兼容

- DSH: 0.2.0-rc.2, 0.2.1-rc.2, 0.2.1-rc.3, 0.2.2-rc.1, 0.2.2-rc.2, 0.2.2-rc.3. No DSH upgrade, new Host RPC or runtime dependency.
- Helper remains **0.13.5**, SHA-256 `95749359a6a0b6523fd34ac951eb78baf97757da4f5b8b0ab3aea7095ab14708`.
- A failed query still reports its original error. Suppression is not proof that SSH is down, and it does not repair dependencies. An admitted recovery query follows DSH's original timeout/cancellation; its running time is not included in the 2-second cooldown.
- Final CI and actual-package verification will be appended to the Release after acceptance. Real SSH tests inject failure only in a disposable command; they do not interrupt user connections or simulate a network outage. Windows CI is not a maintainer Windows Desktop GUI acceptance claim.

## Rollback / 回退

Install the pinned [v0.13.6 archive](https://github.com/CrazyShout/dsh-ssh-remote/releases/tag/v0.13.6) through the official plugin page and reload after saving work. It retains the Windows Git routing fix but has no query cooldown.
