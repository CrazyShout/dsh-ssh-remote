# v0.11.2 — SSH connection indicators / SSH 连接状态标识

## 中文

- 顶部与空白会话的 `SSH · 主机名` 入口增加 6px 状态圆点；远程工作台使用同一状态来源。悬停和键盘聚焦显示完整路径及具体原因，点击仍只打开工作台。
- 绿色表示已连接；黄色表示安装、连接、重连或能力受限；灰色空心表示未连接/未知；红色表示连接错误。颜色使用 DSH 主题变量，不闪烁，也不只用颜色传达状态。
- 可见界面共享每五秒一次的只读查询，隐藏时停止；查询失败、十秒超时及客户端连接丢失时清除旧绿点。忽略其他会话、旧连接代次及超时后的迟到响应，不自动连接或断开 SSH。

兼容基线保持 DSH **0.2.0-rc.2 / 0.2.1-rc.2**；helper **0.11.0** 与内容哈希不变，Host RPC、传输格式、终端执行与 SSH 配置均不改动。

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.11.2/dsh-ssh-remote-0.11.2.tgz'
```

Desktop 使用官方插件页面安装同一完整 URL，启用后重启；重启前保存草稿、暂停传输并结束终端。安装包与 `SHA256SUMS`、发布清单一并提供，安装仍会下载运行依赖。回退版本为 **v0.11.1**。

绿点表示最近确认的 SSH/helper 连接状态，不保证全部远端能力，也不保证瞬时检测物理断网。文件夹小地球、工作区行尾主机名和状态仍待 DSH 提供公开扩展接口；本版保留官方列表，不修改桌面安装包。

## English

Add a 6px, theme-aware SSH status dot to the existing header/blank-session badge and remote workbench. Both surfaces share visibility-bound five-second read-only polling and accessible hover/focus details. Connected is green; installing/connecting/reconnecting/degraded is amber; disconnected/unknown is hollow gray; errors are red. Failed/timed-out queries and carrier loss clear stale green indicators; late responses cannot restore them after a Session or connection-generation change.

No automatic SSH connect/disconnect, native-sidebar replacement, new RPC, runtime dependency, configuration migration or DSH upgrade. Helper 0.11.0 and its content hash are unchanged. Supported baselines remain DSH 0.2.0-rc.2 / 0.2.1-rc.2; rollback is v0.11.1. Install the archive URL above via the official plugin page or Web CLI, verify SHA256SUMS, enable and restart. Dependencies are still downloaded at install time.

Green represents the most recently observed SSH/helper connection, not verification of every remote feature or instantaneous physical-network failure detection. Folder globe badges and workspace-row trailing status await public upstream extension points.
