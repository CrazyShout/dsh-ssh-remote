# v0.11.1 — SSH compatibility and remote skills / SSH 兼容性与远程技能

## 中文

- [#28](https://github.com/CrazyShout/dsh-ssh-remote/issues/28)：修复 fish / tcsh 登录 shell 对嵌套引号的改写。helper 安装与直连 subprocess 共用编码包装，通过已有 Python 运行时执行原 POSIX 脚本；保留 stdin、退出码、哈希与文件权限校验，不修改登录 shell，不留下临时 shell 脚本。
- [#29](https://github.com/CrazyShout/dsh-ssh-remote/issues/29)：目录路径输入停顿 300 ms 后自动导航；保留 Enter / 前往，关闭拼写检查、自动纠正与自动大写。错误路径保留输入和原列表，不能误提交旧目录；支持中文输入法并忽略过期响应。
- [#27](https://github.com/CrazyShout/dsh-ssh-remote/issues/27)：通过官方 skill provider 发现、加载远端项目与用户的 `.dsh/skills`、`.agents/skills`。支持 `SKILL.md` 目录包和平铺 Markdown、调用开关、相对资源目录与同名优先级；本机独有和内置技能保留。

兼容 DSH **0.2.0-rc.2 / 0.2.1-rc.2**。helper 保持 **0.11.0** 和原内容哈希，传输格式仍为 v1。新增 Windows 技能路径/注册表 CI，不据此声称 Windows Desktop 与全部 SSH 功能已实测。

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.11.1/dsh-ssh-remote-0.11.1.tgz'
```

Desktop 使用官方插件页面安装同一完整 URL，启用后重启。回退包为 v0.11.0；旧包不含本轮修复。安装包与 `SHA256SUMS`、发布清单一并提供，安装仍会下载运行依赖。

技能正文单文件最多 256 KiB；每次发现最多 1000 个候选文件、8 MiB 内容，最多四路读取；达到上限或遇权限错误会记录诊断并标记发现不完整。缓存最多 60 秒，不做 SSH 后台轮询。仅覆盖四个默认目录，不跟随符号链接、不读取远端自定义 DSH_HOME/DSH_AGENTS_HOME；鱼壳连接支持不等于新增 fish 命令状态 hook。

## English

Fixes #28, #29 and #27: cross-login-shell script quoting, debounced directory navigation with draft/IME protection, and remote project/user skill discovery through DSH's public provider registry. Existing local-only/bundled skills, invocation flags, native UI and SSH policy remain intact.

Baselines remain DSH 0.2.0-rc.2 / 0.2.1-rc.2. Helper 0.11.0 and its content hash are unchanged. Install the full archive URL above through the official plugin page or Web CLI, enable and restart; verify SHA256SUMS. v0.11.0 remains the rollback point.

Remote skill discovery covers the four default roots, directory bundles and flat Markdown. It does not follow symlinks or discover custom remote DSH_HOME/DSH_AGENTS_HOME. Limits: 256 KiB per skill, 1000 candidate files / 8 MiB per scan, four concurrent reads, 60-second catalog expiry with no SSH polling. Permission/budget failures are incomplete observations, not an authoritative empty catalog. Windows path/registry CI is narrower than full Windows Desktop/SSH acceptance. Terminal command observation remains Bash/Zsh-only.
