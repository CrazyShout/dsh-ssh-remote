# 0.13.0 — Native workflow polish / 原生体验打磨

## 中文

- 官方插件详情新增“开始使用”；界面跟随 DSH 中英文设置，不另设开关。
- 设置、SSH 标识和工作台共享状态查询；隐藏时停止轮询，超时不叠加请求。配置读取不再等待远端探测，本机/SSH 目录独立加载。
- 复用官方路径、复选框和剪贴板，统一操作层次；传输进度按任务展示，目录授权能力提前提示。

## English

- Contextual Getting started guidance and Chinese/English UI following DSH.
- One visibility-aware connection observer, without overlapping timed-out requests. Configuration reads no longer wait for remote probes; local/SSH sources load independently.
- Native controls, consistent actions, task-owned transfer progress and early folder-capability guidance.
- Includes PR #33's bounded environment revalidation and IME-safe quick open.

## Installation / 安装

Paste into Desktop/Web **Plugins → Add plugin**, or use:

```sh
dsh plugin --profile web add 'https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.13.0/dsh-ssh-remote-0.13.0.tgz'
```

Runtime dependencies still download through the official installer. Use the full URL: the npm package with the same name is a different project.

Acceptance baselines: **DSH 0.2.0-rc.2 / 0.2.1-rc.2**. Completed checks are recorded in [acceptance](0.13.0-acceptance.md).

## Compatibility and limits / 兼容与限制

- Helper **0.11.0**, SHA-256 `3c3b35a6a6c20703053cb06d8ee770031d92266750d7909bc41e96087f8d09be`, is unchanged. No SSH configuration rewrite or transfer-format migration.
- Updates may reload SSH: save drafts and pause transfers first. DSH never restarts automatically. Source-linked installs remain Git-managed.
- Folder transfers require File System Access in Desktop/supported secure Chromium; ordinary file uploads remain available elsewhere.
- Existing editor capacity, per-run drafts, 1 TiB transfer limits and native workspace-row extension boundaries are unchanged. Synthetic ranking is not SSH throughput.
- Rollback: install [v0.12.0](https://github.com/CrazyShout/dsh-ssh-remote/releases/download/v0.12.0/dsh-ssh-remote-0.12.0.tgz), then reload/restart as instructed. Workspace mappings and migrated OpenSSH configuration remain.
